# UniEnable

UniEnable is a Java command-line application for managing dated activities and
checking recorded campus accessibility information.

Useful links:

* [User Guide](UserGuide.md)
* [Developer Guide](DeveloperGuide.md)
* [About Us](AboutUs.md)
* [Team Project Portfolios](team/README.md)

## Publication and link checks

For a GitHub Pages deployment from this repository, select the `master` branch
and `/docs` folder as the publishing source in the repository's Pages settings,
or use the team's configured Pages workflow. Deploy the reviewed documentation
revision before checking the public pages.

The Developer Guide uses repository permalinks for Java files, resources, and
root-level files outside `docs`. Diagram and image navigation points to explicit
index pages and individual assets, rather than relying on directory listings.
When the implementation changes, refresh source permalinks to the matching code
revision along with the feature explanation.

After deployment, open the User Guide, Developer Guide, About Us, portfolios,
diagram index, and image index from the published home page. Follow a source-code
link, a dataset link, an index link, and an image link from the Developer Guide;
check diagram legibility at normal desktop and narrow viewport widths.
